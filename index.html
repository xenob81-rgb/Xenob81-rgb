Quiet by Design

Charcoal surfaces and soft borders create hierarchy. Coral is reserved for active states, so important controls stand out without overwhelming the frame.

The player uses the Video.js 10 HTML custom-element API and its skin system, with native playback and supported controls.

Made for Every Screen

The layout adapts for tablets and phones, with a fluid player, readable typography, and reduced spacing on narrow screens.
